# 全局外观

基于上游 `main` 的 `af050d7`（v1.5.2）。PR #30 已合入上游，私信布局随主线提供。

## 使用

首页「更多 → 设置 → 界面」中，「跟随系统」「亮色」「暗色」同排显示。首次安装默认暗色，需手动选择「跟随系统」才会随设备外观切换。选择保存在本机，重启后保留。经典、默认、简洁和极简布局共用这项设置。

| 颜色用途 | 亮色（sRGB） | 暗色（sRGB） |
| --- | --- | --- |
| 应用全局页面底色 | `#FCFCFC` | `#161616` |
| 聊天列表 | `#FCFCFC` | `#161616` |
| 聊天室 | `#FFFFFF` | `#000000` |
| 置顶会话 | `#F5F5F5` | `#242424` |

修复搜索结果、我的及作者页视频封面遮罩越界，在页面右侧形成残影的问题。共用网格将文字阴影与渐变裁剪在封面边界内，保留上游封面内部的渐变效果。

视频与图片像素保持原色。环境光继续按用户原有偏好显示。直接叠在视频上的标题、频道和说明保留媒体前景色；视频上的液态玻璃互动控件和导航始终使用暗色样式。互动栏沿用上游阴影，没有新增阴影增强。

搜索、个人资料、关注列表、消息、通知、评论、设置及相关弹窗使用语义文字和背景色。内嵌网页同步原生外观，暗色网页使用官网原有的背景和文字配色；私信同步官网的 chatLight/chatDark 主题外壳、theme 偏好、页面主题事件及私信 SDK 的主题接口，让聊天网页的文字、气泡和输入框使用官网原生亮暗主题。仅聊天室画布使用表中的黑白底色；更换主题原位更新，不重新加载网页。网页样式仅在抖音域名注入，不反色视频、封面或头像。

## 验证范围

只测试 iPhone Duo 外屏、内屏。Device Hub 音频输出设为 None；视频内容使用真实联网推荐流，观看截图前暂停。自动测试覆盖三项同排选择、默认暗色及手动选择跟随系统、主题持久化、两种主要布局，以及 WKWebView 切换后的文档与草稿保留。私信会话动作、输入框与草稿使用离线会话夹具验证，不对真实联系人执行发送、删除或置顶；这类夹具不替代联网视频验收。

构建与截图记录位于被忽略的 `build/appearance/`。截图原图和压缩副本不提交到 Git。Release 不包含 DEBUG 测试画面；最低系统要求保持 iOS 26.0。
