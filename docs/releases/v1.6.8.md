# DouDuo 1.6.8 · 展开屏开评论不再从头播 · 「我的」下拉刷新

小修复版。包为**未签名 IPA**，需要自行签名安装。

## 修复
- iPhone Duo 展开内屏横屏时点评论（评论从右侧出来），视频会从头重新播放（工单 B13）：以前一开关侧栏评论，整个播放器都会被拆掉重建。现在开关评论只改变视频大小，接着原来的位置播。
- 同一场景下视频底部手势条那一截露出一条白边：现在视频的模糊背景光铺到屏幕最底边。

## 新功能
- 「我的」页可以下拉刷新：资料（粉丝 / 获赞 / 作品数）和当前这一栏一起重新加载。拉不到时保留原内容，不会清空成白屏。

## 验证与仍需确认的边界
- 侧栏评论不再从头播：作者的 iPhone Duo 真机上确认评论区显示正常、不再从头播；iPad 模拟器横屏日志确认开评论只改尺寸、播放器没有重建。
- 底部白边：改为背景光铺满后，真机上还没有截图复核。如果设置里关了「环境光」，或者视频还没出第一帧，底部那一截会是黑色。
- 已知问题（这一版没修）：刷到直播间再往下滑到下一条视频时，偶尔会顿一下。
