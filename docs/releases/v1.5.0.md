# DouDuo 1.5.0

1.3.15（100）之后的大版本更新：推荐流改为只用网页首页「推荐」、新增实时环境光、「更多」菜单与设置页重做，并合入社区 PR #24（标签搜索与过滤）与 #26（资料封面、经典频道跟手等）。包为**未签名 IPA**，需要自行签名安装。

## 推荐流：推荐什么就放什么
- 推荐只用抖音网页首页的「推荐」流，**去掉了「精选」源**和来源切换。精选横屏长视频多、偏大众内容，刷不到关注的人，和抖音 App 的推荐差距很大。
- **去掉「竖屏 / 横屏短视频占比」**，也不再按约 70% 竖屏重排：按推荐接口给的顺序原样播放。
- 「横屏时只放横屏内容」保留：横着看时只放横屏视频，竖屏的先留着，转回竖屏或关掉开关后按原顺序接着放。

## 实时环境光
- 视频没铺满屏幕时，四周背景跟着当前画面颜色实时变化（取当前播放帧缩小、模糊、压暗），底色保持黑色。
- 「更多 → 设置 → 播放 → 环境光」五档：亮 / 中 / 暗 / 很暗 / 关，**默认「中」**。铺满时不取帧；VLC 兜底播放或关闭时退回模糊封面。

## 「更多」菜单与设置页
- 「更多」第一排：**转发 / 不感兴趣 / 下载**（不感兴趣改为同色，放在中间）。
- 表层只放当前播放相关的：**倍速、静音、听书模式（后台播放）、自动连播**、发弹幕，最后一项「设置」。经典布局的顶栏「更多」和长按面板同样有自动连播。
- 「设置」改为完整设置页：刷新推荐、界面模式、环境光、按标签过滤、横屏只放横屏、弹幕（显示 / 密度 / 去重）、预缓存与清除缓存、网页版登录、版本与开源仓库。
- 表层已有的开关（静音、铺满宽度、听书、自动连播）不在设置页重复。

## 右侧按钮栏
- 简洁 / 极简模式右侧按钮统一为轻量圆角线框；模块入口外圈进度环参照系统电量环，改为实白、等宽、圆头。
- 缩放按钮按点下去的动作显示：要放大显示朝外箭头，要缩小显示朝内箭头。
- **修复冷启动后右侧按钮栏、模块按钮跟系统信号栏不对齐**（1.3.15 合入搜索分栏后的回归）：只有左右分栏搜索时才忽略水平安全区。
- **输入弹幕或回复评论时**，右侧按钮栏保持原位、变灰且不可点，输入框和发送键在最前层，不再被按钮栏挡住或顶出屏幕；分屏时仍跟随窗格。

## 合屏外屏
- 合屏（铰链合上）时，外屏的竖屏视频留边就靠左贴边，画面大小、裁切和右侧按钮不变。
- 只在系统报告铰链合上时生效；展开、半折叠、分屏都保持原来的居中。

## 消息
- 私信会话按最后联系时间排序：修复「前天」等相对时间被排到前面、旧日期误判成现在的问题。时间文字按抓取时刻解析，解析不了的排到最后。

## 社区贡献
- **#标签与搜索（合入 PR #24，感谢 @zenghongjvn）**：简介里的 `#标签` 加粗可点、直接搜索；推荐页按标签屏蔽（入口在设置页）；Duo 内屏大横屏搜索左右各半，左侧保留当前视频；热搜榜重做；打开搜索结果暂停被盖住的视频，返回恢复原播放状态。
- **资料封面 / 经典频道 / 音频中断（合入 PR #26，感谢 @kikozheng27-creator）**：「我的」页显示资料封面；经典布局频道顺序为直播 → 关注 → 推荐，横滑跟手，切回关注保留浏览位置；非 1x 倍速的音频在系统中断后不再自行重启；去掉直播页未用的定时器。

## 1.5.0 发布后补的修复（同版本重发安装包）
- **打开 App 时右侧菜单栏整列发灰、点不动**：输入态判断只靠系统键盘通知，第三方键盘或程序化收起时「收起」通知不发，状态就停在「正在输入」。
- 现在以「有没有输入框真的在编辑」为准：菜单栏出现、回前台、键盘状态变化时各核对一次；补上只发「键盘位置变化」「键盘已收起」的情况；切后台先清状态。冷启动菜单栏正常可点，输入时照旧变灰禁点。
