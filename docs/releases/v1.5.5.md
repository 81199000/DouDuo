# DouDuo 1.5.5

这一版重点：**弹幕和私信更顺滑**，新增亮色模式。包为**未签名 IPA**，需要自行签名安装。

## 外观
- 新增亮色模式：「更多 → 设置 → 界面」可选跟随系统、亮色、暗色。视频画面区域始终保持纯黑。

## 弹幕
- 弹幕重新做了一遍，参考抖音：边播边出，开头不再一卡一卡，滚动更顺滑（支持 120Hz）。
- 长弹幕跑得快、短弹幕跑得慢，字号加大，更好读。
- 快进或拖动进度后清屏，从新位置重新出弹幕。
- 长视频的弹幕能一直拉到结尾，不再只有开头一小段。

## 刷视频
- 长按加速开始和松手时不再卡一下，角标显示实际倍速。
- 经典模式下，右侧控制区长按任意位置都能加速。
- 快速小幅上滑不再松手弹回；展开屏左右滑切频道的距离不再翻倍。
- 自动连播切下一条时会滑上来，而不是直接跳过去。
- 视频标题默认只显示一行，点「展开」看全部。
- 图文作品支持双击点赞。
- 从搜索、「我的」打开的视频，点作者头像直接进入作者主页。
- 简洁、极简模式下，从搜索、作者主页、我的、消息打开的视频，进度显示在返回键外圈。

## 私信
- 进聊天像微信一样：看过的会话再点进去，立刻显示上次的聊天内容，不再每次转圈、闪一下。
- 首页点「消息」打开更快，点会话时列表不再闪一下。
- 信息页改为靠左排版，右侧栏和视频页同款：返回、互动、粉丝、系统、陌生人竖排，图标下带文字；内外屏、横竖屏一致。
- 「信息」和「我的」合在一页，右侧栏上下两个入口直接切换，不用再返回。
- 置顶改到左滑菜单里，右滑留给返回手势。
- 横屏分栏时，联系人和聊天之间加了明显的分割线。

## 我的
- 修复「我的 · 作品」封面全黑。

## 其他
- 经典模式下，Duo 横置时顶部频道标题居中。
- 半折叠时，视频和评论区按折痕对齐。
