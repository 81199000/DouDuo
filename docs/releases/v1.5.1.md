# DouDuo 1.5.1

1.5.0 之后的修复版：推荐重新以竖屏为主，左缘右滑返回覆盖到所有二级页，点开的视频和推荐页布局一致。包为**未签名 IPA**，需要自行签名安装。

## 推荐：竖着看重新以竖屏为主
- 1.5.0 改成按推荐接口原顺序播放后，网页「推荐」流本身竖屏只占一到三成，竖着刷几乎全是横屏。
- 恢复竖着看时**约 70% 竖屏**均匀穿插（竖横竖竖横…），同方向内仍保持推荐原顺序；刷新或转屏后第一条先放竖屏。
- 竖屏一时不够时按原顺序补上，列表不会断；「横屏时只放横屏内容」不变。

## 左缘右滑返回上一层
- 从屏幕最左边往右滑即可返回：博主主页 / 我的 / 搜索结果 / 私信与通知里点开的视频、「我的」页、博主主页、关注与粉丝列表、搜索页、评论区相关搜索、评论大图。
- 经典布局右半屏的博主窗格、内屏左右分屏的搜索窗格左边是分界线，不做边缘返回。

## 点开的视频与推荐页界面同步
- 默认 / 简洁 / 极简布局下，从博主主页、我的、搜索、消息点开的视频，评论区改为与推荐页同一套布局：横屏从右侧滑出、视频缩窄；半折叠按折痕常驻分屏（书本左右、桌面上下）；竖屏窄屏才从底部弹出半屏。
- 点开的视频补上「自动连播」（打开后播完自动下一条，到底自动加载）、右侧搜索按钮和「更多 → 设置」。
