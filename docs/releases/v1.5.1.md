# DouDuo 1.5.1 · 修复菜单栏开机变灰点不动

1.5.0 打开 App 后右侧菜单栏整列发灰、点不动的问题。包为**未签名 IPA**，需要自行签名安装。

## 问题
- 1.5.0 为了让「输入弹幕 / 回复评论时菜单栏变灰不可点」，菜单栏的禁用状态记在一个跟着 App 走的开关里。
- 这个开关只靠系统「键盘弹出 / 收起」通知切换。第三方键盘、程序里主动收起输入框、切到后台再回来时，**收起的通知经常不发**，开关就一直停在「正在输入」，于是打开 App 时菜单栏已经是灰的，还点不动。

## 修复
- 判断「是否正在输入」改为**以当前有没有输入框真的在编辑为准**：菜单栏出现时、从后台回到前台时、键盘状态变化时各核对一次，没有输入框在编辑就立刻恢复正常。
- 同时补上只发「键盘位置变化」和「键盘已经收起」这两种通知，第三方键盘收起也能识别。
- 切到后台时先把状态清为「没在输入」，避免回来时残留。

## 验证
- 冷启动后不加任何输入，菜单栏正常亮度、按钮可点（自动化测试已加入这条断言）。
- 打开弹幕输入框后菜单栏变灰禁点、输入框和发送键在最前层且紧贴键盘上方；关掉输入后菜单栏立即恢复。
- 全部脚本测试通过，模拟器与真机 Release 编译通过。
