# DouDuo v1.3.10 · 倍速控制重做、后台播放、直播间选择与消息中心增强

## 播放
- 新增**播放速度**：设置 → 播放设置 → 播放速度，可选正常 / 0.75× / 1.25× / 1.5× / 2.0×，改完**当前视频立刻生效**。
- **长按下滑锁定 2 倍速**：只锁当前这一条视频，换到下一条自动回到设置里的速度。
- **长按上滑取消倍速**：不用进设置，长按中上滑直接回到设置速度。
- 只要不是 1 倍速，画面左上角**常驻显示当前倍速**；锁定状态额外提示「已锁定本条 · 长按上滑取消」。
- 设置里的速度与长按锁定完全分开：长按锁 2 倍不会改动设置，设置改速度会撤掉本条的临时锁定。
- 新增**后台播放（听书）**开关（设置 → 播放设置），打开后切到后台/锁屏继续放，支持锁屏与控制中心的播放、暂停、倍速控制。

## 直播
- 直播间新增**直播间选择列表**，可直接在多个直播间之间切换。
- 直播支持**画质选档**，网络不好时手动降档。

## 修复
- 修复长按下滑锁不上 2 倍速：长按手势原先手指移动 12pt 就被取消，根本到不了锁定判定；现在长按期间跟随手指，下滑 50pt 判定锁定。
- 修复「更多」里的倍速选择无效：改为设置页内的选项列表，播放器即时应用。
- 倍速入口从「更多」菜单移出，避免误点。

## 消息中心（75）
- **评论通知回复按钮**：消息 → 互动里可直接回复评论通知；长评论可展开全文；点评论跳视频并自动定位到该评论。
- **评论配图显示**：带图的评论通知在消息列表显示最多 3 张缩略图，对齐抖音原版互动区。
- 旧版本本地缓存没有配图字段时自动作废重拉，无需手动清数据。
- 通知解析容错：单条脏数据不再炸掉整个列表，失败原因写入日志便于定位。

## 评论 / 界面（75）
- **竖屏评论区锁死半屏**：看视频打开评论区固定 62% 高度，上滑不再撑满整屏。
- **横屏关闭键左移**：避让右上角时间显示，不再重叠。
- 「展开更多回复」上方加间距，减少误触下面的回复评论。

## 图标（75）
- 新 App 图标：抖音风音符当字母 d + duo 元素，黑底青红错位。

## 安装
- 支持 iOS / iPadOS 17.0 及以上。
- 下载附件 `DouDuo-1.3.10-unsigned.ipa`，用爱思助手 / Sideloadly 等工具自行签名；**未签名原包不能直接安装**。
- 免费 Apple ID 签名通常 7 天有效，到期需重新签名；同账号覆盖安装，不要先卸载。
- GitHub 下载：https://github.com/81199000/DouDuo/releases/latest
- Gitee 国内下载：https://gitee.com/remon8/douduo/releases
- 完整图文教程见仓库 README「下载与签名安装」。
