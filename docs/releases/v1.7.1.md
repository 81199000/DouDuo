# DouDuo 1.7.1 · 发布作品 · 收藏夹与批量管理 · 原生看大图

包为**未签名 IPA**，需要自行签名安装。

## 发布作品
- 「我的」页新增「发布作品」：直接打开抖音官方创作者中心的上传页，用同一个登录，能发视频、发图文、管理作品。选封面、写标题、加话题、定时发布都在抖音自己的页面里完成。

## 收藏
- 点五角星收藏后，底部会出现「收藏成功　加入收藏夹 >」，点一下就能选收藏夹（和官方 App 一样），也能当场新建收藏夹。
- 「我的 · 收藏」改成官方那样的分类：我的收藏夹 / 视频 / 音乐 / 合集 / 短剧。收藏夹可以新建、改名、设为私密、删除；合集和短剧可以批量取消收藏。

## 我的 · 批量管理
- 作品、喜欢、收藏三栏右侧多了「管理」，可以多选：作品能批量删除或改可见范围（公开 / 好友可见 / 私密）；喜欢能批量取消；收藏能批量取消或放进收藏夹。

## 消息
- 互动消息的筛选和网页版一致：全部消息 / 粉丝 / @我的 / 评论 / 赞 / 推荐。「@我的」会显示谁在哪里提到了你，点开直接跳到那条评论。
- 长按通知可以删除；「某某等 N 人赞了你」可以点开看全部点赞的人。
- 私密账号收到关注请求时，可以直接「通过 / 拒绝」。
- 大屏展开竖屏时，互动消息顶部「全部互动」点不了：修复。

## 看大图
- 私信和评论里的图片改用原生看大图，手感和系统「照片」一样：双指缩放、双击放大、下滑关闭，多张可以左右切换。
- 横屏时点开私信图片后退不出来：修复。

## 其他
- 长按评论可以翻译、复制。
- 转发面板里新增「复制短链」（v.douyin.com 短链接）。
