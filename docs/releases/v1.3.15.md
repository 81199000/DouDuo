# DouDuo 1.3.15

1.3.14（92）之后的一组体验修复（来自 issue #4、#15、#16 的反馈），并合入社区 PR #17（Duo 经典布局）与 #23（翻页更利落）。包为**未签名 IPA**，需要自行签名安装。

## 非 Duo 机型顶栏点不到（#16）
- 默认模式的顶栏原本按 iPhone Duo 外屏往上推了 80pt 贴顶，在其他 iPhone（含 LiveContainer 打开）上会被推进状态栏和灵动岛里，点不到。
- 现在只有 Duo 保持原来的贴顶位置；其他机型的顶栏放在状态栏下沿，倍速角标也跟着下移，不再和顶栏重叠。

## 长按加速（#4 后续反馈）
- **触发更快**：长按从 0.5 秒改为 0.3 秒，更跟手。
- **简洁 / 极简模式**：长按加速时右侧整列（圆形入口、点赞评论收藏、更多）和作者标题一起淡出，与默认模式一致。
- 右侧圆形入口保持原设计：长按只显示作者和标题（极简模式），不触发加速；轻点打开菜单。
- **简洁 / 极简模式底部留白减少**：这两种模式没有底部进度条（进度画在入口外圈），作者和标题整体下移，不再给进度条留空。

## 半折叠时竖屏短视频变少
- 1.3.14 把「现在是横着看还是竖着看」改成按半折叠后视频那一块的形状来判断。竖着拿的桌面半折叠，视频块接近正方形（约 466×455）甚至偏宽，被判成「横着看」，推荐流按「横屏时只放横屏内容」只排横屏视频，竖屏短视频几乎刷不到。
- 现在恢复 1.3.13 的判断口径：按整屏形状判断横竖，半折叠的分屏布局本身不变。

## 评论栏与系统竖栏的间距（#15）
- 评论栏在右侧时（书本半折叠 / 内屏展开），按系统竖栏（时间、信号）的实际宽度收窄评论栏，不再整块往左平移；评论标题行也不再额外让出 88pt，右侧空隙明显变小。
- 半折叠按真实折痕切分（1.3.14 起）保持不变。

## 可选「经典」布局（合入 PR #17，感谢 @zenghongjvn）
- 「更多 → 界面」新增 **经典**：系统 Dock（我的 / 私信 / 首页）、右侧互动胶囊、清屏按钮、双指捏合切换铺满、长按左右两侧加速 / 中间打开设置面板、新的分享与评论面板、左滑进作者页（内屏左右并排）。
- **默认不开启**，不选就和以前一样；仅在 iOS 27.1 及以上显示该选项。
- 合入时的调整：版本号沿用本版；半折叠选片和评论栏让开系统竖栏沿用本版修复；长按时长用本版的 0.3 秒，同时采纳 PR 的「手指一拖动就取消长按」，上下滑不再误触倍速；经典布局左上角「更多」三个点加上阴影，亮色画面上也能看清。
- 最低系统要求随之提高到 **iOS 26.0**（iPhone Duo 出厂即 iOS 26）。

## 上下翻页更利落（合入 PR #23，感谢 @AppleLiang96，关联 #22）
- 松手后页面滑到位的动画从系统默认约 0.43 秒缩短到约 0.1 秒，连续刷更跟手。只改这段动画，翻到哪一条、加载和播放都不变。
- 作用于推荐、关注，以及从作者主页 / 喜欢 / 收藏点进去的视频列表；直播、评论区、图集不受影响。
- 固定为最快一档，**不提供设置菜单**；系统开启「减少动态效果」时自动使用系统默认分页。

## 验证与仍需确认的边界
- 模拟器：iPhone 18 Pro 默认模式顶栏在状态栏下、倍速角标在顶栏下方不重叠；iPhone Duo 外屏顶栏贴顶位置不变；简洁模式两台机型底部信息下移、无遮挡；Duo 上长按视频画面进入加速时右侧栏与作者标题淡出。
- **未在模拟器上验证**：评论栏与系统竖栏的间距（模拟器无法切换到展开 / 半折叠姿态），需要真机确认。
- LiveContainer 环境未单独测试，修复依据是机型判断（非 Duo 一律放在安全区下）。
- 全部 20 个脚本回归通过（`test_live_categories.py` 由 PR #17 一并修复）。
- 经典布局与快速翻页已在 iPhone Duo 真机试用；iPad、iOS 26 真机、画中画仍未测试。
