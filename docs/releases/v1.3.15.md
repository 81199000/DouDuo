# DouDuo 1.3.15

1.3.14（92）之后的一组体验修复，来自 issue #4、#15、#16 的反馈。包为**未签名 IPA**，需要自行签名安装。

## 非 Duo 机型顶栏点不到（#16）
- 默认模式的顶栏原本按 iPhone Duo 外屏往上推了 80pt 贴顶，在其他 iPhone（含 LiveContainer 打开）上会被推进状态栏和灵动岛里，点不到。
- 现在只有 Duo 保持原来的贴顶位置；其他机型的顶栏放在状态栏下沿，倍速角标也跟着下移，不再和顶栏重叠。

## 长按加速（#4 后续反馈）
- **触发更快**：长按从 0.5 秒改为 0.3 秒，更跟手。
- **简洁 / 极简模式**：长按加速时右侧整列（圆形入口、点赞评论收藏、更多）和作者标题一起淡出，与默认模式一致。
- **按住右侧圆形入口也能加速**：推荐 / 关注页按满 0.3 秒即进入 2 倍速，松手恢复；轻点仍是打开菜单。
- **简洁 / 极简模式底部留白减少**：这两种模式没有底部进度条（进度画在入口外圈），作者和标题整体下移，不再给进度条留空。

## 评论栏与系统竖栏的间距（#15）
- 评论栏在右侧时（书本半折叠 / 内屏展开），按系统竖栏（时间、信号）的实际宽度收窄评论栏，不再整块往左平移；评论标题行也不再额外让出 88pt，右侧空隙明显变小。
- 半折叠按真实折痕切分（1.3.14 起）保持不变。

## 验证与仍需确认的边界
- 模拟器：iPhone 18 Pro 默认模式顶栏在状态栏下、倍速角标在顶栏下方不重叠；iPhone Duo 外屏顶栏贴顶位置不变；简洁模式两台机型底部信息下移、无遮挡；Duo 上长按圆形入口进入加速、右侧栏与作者标题淡出。
- **未在模拟器上验证**：评论栏与系统竖栏的间距（模拟器无法切换到展开 / 半折叠姿态），需要真机确认。
- LiveContainer 环境未单独测试，修复依据是机型判断（非 Duo 一律放在安全区下）。
- `test_live_categories.py` 仍失败，该问题在本版之前已存在。
