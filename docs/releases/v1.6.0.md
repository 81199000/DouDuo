# DouDuo 1.6.0

这一版重点：**App 内登录与多账号，新增离线视频和 Apple Watch**。包为**未签名 IPA**，需要自行签名安装。

## 新增功能

### 登录与账号
- App 内直接登录：支持手机验证码和扫码（用另一台手机的抖音扫）。没登录时点「我的」会自动弹出登录页。
- 支持多个账号：在「我的 → 账号」里添加、切换、退出、移除，切换后推荐和消息立刻换成对应账号的。

### 离线视频
- 「更多 → 设置 → 缓存 → 离线视频」可一次下载 50 / 100 / 150 / 200 条，下载时可以继续刷；可开启 Wi-Fi 下自动补足。
- 断网或视频加载失败时，推荐页自动改播本地视频，恢复联网后接回推荐。
- 全部刷完的保留 3 天，没刷完的连续 7 天没看才清理。

### 储存空间
- 「设置 → 缓存 → 储存空间」用环形图显示占用明细，一键清理缓存，登录、消息、设置和离线视频都保留。
- 打开 App 时自动清理以前留下的视频下载残留文件。

### 分享
- 「复制链接」改成抖音同款格式（标题 + 链接 + 提示语），粘到抖音也能直接打开。
- 复制了抖音视频链接后打开 DouDuo，会直接播放这条视频。

### Apple Watch
- 新增手表 App：不用在手表上登录，通过 iPhone 刷推荐视频，手表连 Wi-Fi 直接播放，会预存后面几条。
- 在手表上看过的视频会同步为已看。

### 视频与评论
- 评论支持发图片。
- 显示国内作品的发布地区。
- 管理功能：稍后再看、清空历史、拉黑 / 解除拉黑、移除粉丝、删除自己的评论、删除聊天消息。
- 点已选中的「推荐」刷新时，会一直显示「正在刷新视频…」直到出结果；经典模式双击「首页」刷新。

## 修复与改进

### 界面
- 四种界面的评论区统一，评论始终在最上层，不会被菜单栏挡住。
- 半折叠选片调整：竖屏半折叠按横屏挑视频，横屏半折叠按竖屏挑。
- 切换界面模式后接着播同一条、同一进度，不再换一批视频。
- 经典布局：横屏视频打开评论时视频上移、评论在下，展开简介显示作者和评论，内屏横屏状态栏不再挡评论点赞区。
- 「跟随系统」外观现在会随系统实时切换亮色 / 暗色，设置页也一起变。

### 我的 / 信息
- 「我的」顶部改成和「消息」一致的标题，资料封面不再超出边界。
- 「我的」和「信息」两页的返回键位置固定，不再上下跳；「账号」按钮不再和返回键重叠。
- 「我的」页不再显示互动、粉丝、系统、陌生人；有未读消息时「信息」上显示红点。
- 登录或切换账号后，信息页能马上加载新账号的会话。
- 切后台再回来，时间和信号不再消失。
- 粉丝和关注列表不再只显示 20 个人。

### 刷视频
- 刚打开 App 时上滑不再要滑好几次才翻页。
- 经典布局重复点击「首页」不再跳回第一条视频。
- 快速小幅上滑不再松手弹回；展开屏左右滑切频道的距离不再翻倍。
