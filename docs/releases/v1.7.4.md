# DouDuo 1.7.4 · 长视频不卡了，直播也有环境光

包为**未签名 IPA**，需要自行签名安装。

## 长视频：退出回来、快进，都不卡了
- **退出 App 再回来接着播**：以前长视频切到后台再回来，常常卡十几秒、有画面没声音，等一会儿又从头开始。现在回来就从原来的位置接着播，声音也一起回来。
- **快进拖远了不再卡死**：拖进度条到很远的地方，画面不会停住不动，松手就开始播；拖动时预览小图也不再抢松手后要播的那段。
- **不再动不动停下来缓冲**：已经缓存够了还在「等一下防卡顿」的情况去掉了，内容够了就接着播。
- **拖动后退出再回来**：不会先卡一段、黑屏、没声音。

## 倍速戴耳机声音不变小
- 戴耳机开 2 倍速，以前声音会明显变小，现在会自动补回音量，听起来跟 1 倍速一样大，也不会破音。

## 刷到直播也有环境光
- 推荐里刷到直播间，画面两边和视频一样铺上环境光，跟设置里的环境光档位一致；铺满屏幕、手机发热或不在当前这条时不做，省电。

## 修复
- 大屏横屏打开再关掉评论，视频不再往回跳几秒（工单 B13）。
