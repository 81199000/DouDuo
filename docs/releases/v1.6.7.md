# DouDuo 1.6.7 · 修复点「直播」卡死

小修复版。包为**未签名 IPA**，需要自行签名安装。

## 修复
- 推荐里刷过直播间后，点顶部「直播」整个 App 卡住、十几秒后闪退：直播播放器关闭时偶尔会卡在停声音这一步，以前是在界面线程上等它，界面就跟着冻住。现在改到后台关闭，卡住也不影响界面。
- 推荐里刷到直播间时不再先显示封面再切到直播画面（会闪一下），没出画面前是黑底。
- 顶部「信息」和「关注 / 推荐 / 直播」没对齐（低一截）：已对齐。
- 「关于 → 开源仓库」改为打开 GitHub 新仓库 WuWeiDuo/DouDuo。

## 验证与仍需确认的边界
- 点「直播」卡死：作者的 iPhone Duo 真机上，修复后再遇到直播播放器关不掉时，日志记到「已在后台关闭」，App 没有卡住或闪退。
