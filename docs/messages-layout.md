# 消息页布局与验收

基于 **DouDuo v1.5.0** 优化私信页与视频分享体验，让页面更接近原生 App；已 rebase 到上游 `main`（`c35e9ed`），保留最新键盘、菜单与播放修复。

感谢作者对经典布局的认可与合并。

### 1. 消息列表背景

消息列表使用 sRGB `#161616`，置顶消息使用 `#242424` 区分，并与聊天页形成色彩区分。每个会话增加分割线，置顶会话不再显示图钉；其余会话按最近消息时间排序。

### 2. 左右页面手势

大横屏支持拖动两栏交界处调整显示比例；继续向左拖动，可将列表收为头像窄栏。保留拖动手势，隐藏可见拉条。横向半折时按物理折痕 1:1 显示，大竖屏与外屏使用单栏。

### 3. 列表页火花图标

在联系人昵称后同步显示火花图标及文本，聊天顶栏与列表保持一致。

### 4. 列表页消息分类

将互动消息、粉丝消息、系统消息、陌生人消息集中为一栏入口；头像窄栏下收为“消息分类”菜单。

### 5. 消息栏滑动手势

左滑显示“不显示”和“删除”，右滑显示置顶或取消置顶；删除前需要确认。“不显示”仅隐藏当前账号在本机的会话列表项，保留聊天记录，收到新消息或从分享反馈打开该会话时恢复显示。

### 6. 聊天页布局

- 移除顶栏整片背景蒙版，改为联系人头像、名称、火花组成的 Liquid Glass 胶囊；返回与更多按钮由 iPhone Duo 系统工具栏托管，保持白色。
- 移除输入框背景蒙版与额外网页磨砂层，使用原生输入控件和 Liquid Glass 胶囊，保留右侧三个图标的原版样式。输入时不再显示网页附加的“上一个／下一个／完成”胶囊。
- 更多选项改为原生弹窗，选中高光与 Dock 红色一致；关闭时不再闪回网页设置页。
- 点击联系人胶囊，以 App 内作者主页弹窗展示对方资料；缺少可用身份信息时不跳转网页。
- 经典布局 Dock 交由 Duo 系统管理；从分享反馈“去看看”进入消息时保留 Dock，并避免遮挡输入框。

### 7. 视频分享体验

普通布局保留居中分享面板，经典布局使用底部玻璃面板，并适配内屏右半区。

- 选中好友或群聊后，显示“捎句话”输入框、作品缩略图与“确认发送”按钮。
- 成功后显示反馈弹窗并触发振动，右侧“去看看”直接打开对应会话。
- 加载期间可关闭面板；未发送的准备步骤取消，已发出的请求继续核对结果。部分失败或结果未确认时明确提示，不自动重复分享。

### 8. 会话切换与文字层级

- 陌生人列表仅在进入该分类时扫描，同账号、同网页结果缓存 60 秒；打开会话会先中断扫描，完成旧扫描清理后再切换，避免新聊天被旧任务关闭。
- 返回立即显示本地缓存列表，网页恢复在后台串行执行；移除固定返回等待、无条件收起等待及返回时的 760 宽度重置。
- 聊天期间暂停会话列表轮询；聊天快照刷新降至每秒一次，输入时每两秒一次。私信文字在本机暂存，点「发送」后才同步到网页编辑器。同步失败时保留草稿，可切换会话或打开更多选项。
- 排序融合上游时间解析：置顶优先，其次服务端最后消息时间，最后使用抓取时刻锚定的时间文案；兼容今天、昨天、前天和年月日，不随重新排序漂移。
- 两种分享布局统一标题、联系人、操作及反馈文字层级；联系人使用随系统缩放的 subheadline，长名称可显示两行。

另修复作者页获赞、关注、粉丝等统计文本颜色不一致的问题。

## 验证与边界

本次 v1.5.0 适配已完成构建、Duo 外屏和内屏横屏在线加载／连续聊天往返、内屏输入框与更多弹窗离线回归、普通／经典分享完整流程，以及辅助功能大字号下的两行长名称回归。在线验证仅打开现有会话与分类，未发送私信或分享。

草稿延迟同步已通过 Duo 离线回归。覆盖输入时不写网页、按下发送后才尝试同步、失败时不触发发送，以及切换会话后恢复草稿。发送结果未确认时避免重复触发。真机测试包已由使用者手动验收。

在线代码路径计时：网页就绪后连续打开会话约 22–82 ms，退出陌生人分类后再次打开约 24–229 ms，返回原生列表状态更新约 0–1 ms；冷启动等待网页初始化约 1.5–3.5 s。上述计时不包含完整转场、渲染与 XCTest 点击等待，也不代表真机帧率。登录态下的内屏横屏连续往返、分类退出后打开聊天和缓存复用均通过；在线已验证空结果缓存命中，未覆盖真实的 89 条陌生人会话列表。89 条会话、冷面板延迟挂载及取消后停止 DOM 修改由离线 JavaScript 测试覆盖。另独立执行生产 Swift 生命周期逻辑，覆盖取消、清理顺序、缓存命中／过期、空结果和跨账号隔离。仍需作者在其有 89 条陌生人会话的 Duo 真机上复测。

以下为本功能此前的完整布局覆盖记录：

- iOS / iPadOS 27.2 模拟器：iPhone Duo 外屏和内屏横屏、iPhone 18 Pro 与 iPad Pro 11 英寸（M5）横竖屏消息页；普通／经典分享、捎句话、成功反馈、去看看及加载中关闭已进行离线回归。
- 新增“不显示”在普通 iPhone 和 iPad 上验证隐藏、新消息恢复与保留聊天记录。
- 分享桥业务回调、精确会话跳转、消息排序、隐藏持久化与旧缓存兼容、输入草稿、更多弹窗和分栏手势已有本地回归覆盖。
- 测试静音、视频暂停；未向真实联系人发送私信。真实服务端送达和实体振动手感需实际安装验收。

最低系统保持 iOS 26.0；Duo 分栏、侧栏和经典布局能力使用 iOS 27.1+。离线夹具只用于 DEBUG 回归，不进入正式 Release 包。
